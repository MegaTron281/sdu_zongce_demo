# SDU 综测成绩管理平台

基于 **Go 后端 + 原生前端（HTML/CSS/JS）** 开发的高校综测成绩全流程管理平台，实现学生申报、班委初审、公示、管理员复审、自动计分、数据导出的一体化数字化管理。

------

## 项目简介

本平台针对高校综合测评业务痛点设计，覆盖**日常申报、集中汇总、多级审核、公示异议、规则配置、数据造册**全流程，支持三大角色协同操作，严格遵循学校综测细则，具备规则可配置、流程可追溯、数据可导出的核心能力。

## 核心设计原则

### 1. 时间轴逻辑

- **日常申报期**：学生随时提交申请，支持活动补录与材料上传
- **综测汇总期**（每年 9 月前后）：关闭申报、完成公示、计分锁定、导出造册
- 不同阶段页面状态与权限自动切换，保证流程合规

### 2. 标准数据流向

```
活动名录 → 学生申请 → 班委初审 → 班级公示 → 管理员复审 → 学院公示 → 计分入账 → 成绩看板 → 导出造册
```

### 3. 一事一议机制

支持特殊申请人工标记、手动赋分，全程留存操作日志，满足特殊情况灵活处理需求。

------

## 角色与功能模块

### 1. 普通学生

- **活动广场**：活动浏览、筛选、快截止提醒、一键申报
- **提交申请**：常规活动申报 / 新活动补录申报，材料上传，分数预览
- **我的申请**：申请状态追踪、驳回修改、异议接收与回复
- **我的成绩**：素质分可视化、总分计算、成绩明细查看
- **公示墙**：全班公示记录查看、异议提交

### 2. 审核学生（班委）

- **审核工作台**：本班申请初审、批量操作、材料核验、特殊情况转交
- **班级申请历史**：本班全量申请记录查询、审核追溯
- **权限边界**：仅查看本班数据，初审不直接计分，操作留痕

### 3. 管理员（辅导员）

- **活动名录管理**：活动录入、学生补录审核、活动上下架
- **加分规则配置**：分值矩阵、上限控制、互斥规则、版本管理
- **复审工作台**：申请复审、分数调整、异议处理、公示管理
- **成绩总览**：班级 / 年级排名、数据统计、异常预警、批量导出
- **系统管理**：账号授权、周期配置、操作日志审计

------

## 申请完整生命周期

1. 学生提交申请 → 系统防重复 / 规则校验
2. 班委初审（通过 / 驳回 / 转特殊）
3. 班级公示（2 天，全班可异议）
4. 管理员复审（通过 / 调整 / 驳回）
5. 学院公示（3 天）
6. 自动计分入账 → 成绩更新
7. 汇总期锁定 → 一键导出造册

## 快速开始

### 1. 环境准备

- 安装 [Go 1.20+](https://go.dev/dl/)
- 安装 Git
- 安装 VS Code 并启用 **Go** 官方插件

### 2. 克隆项目

```
# 克隆到本地
git clone https://gitee.com/你的用户名/sdu_zongce_demo.git
# 进入项目目录
cd sdu_zongce_demo
```

### 3. 安装依赖

```
go mod tidy
```

### 4. 启动项目

#### 普通启动

```
go run main.go
```

#### 热重载启动（推荐开发）

```
# 安装air
go install github.com/cosmtrek/air@latest
# 初始化配置
air init
# 启动监听
air
```

### 5. 访问前端

直接打开项目目录下 `index.html` 文件，或在浏览器访问后端对应前端地址。
