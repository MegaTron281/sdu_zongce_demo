# SDU 综测成绩管理平台

基于 **Gin 后端 + PostgreSQL + Vue 3/Vite/TypeScript 前端** 开发的高校综测成绩全流程管理平台，实现学生申报、班委初审、公示、管理员复审、自动计分、数据导出的一体化数字化管理。

------

## 项目简介

本平台针对高校综合测评业务痛点设计，覆盖**日常申报、集中汇总、多级审核、公示异议、申诉裁决、数据造册**全流程，支持学生、班委、辅导员、系统管理员四类身份协同操作，学生自填申报分数、审核端人工改分留痕，具备流程可追溯、数据可导出、班级数据严格隔离的核心能力。

## 核心设计原则

### 1. 时间轴逻辑

- **日常申报期**：学生随时提交申请，支持活动补录与材料上传
- **综测汇总期**（每年 9 月前后）：关闭申报、完成公示、计分锁定、导出造册
- 不同阶段页面状态与权限自动切换，保证流程合规

### 2. 标准数据流向

```
活动名录 → 学生申请 → 班委初审 → 班级公示 → 管理员复审 → 学院公示 → 计分入账 → 成绩看板 → 导出造册
```

### 3. 一事一议机制

支持特殊申请人工标记、手动赋分，全程留存操作日志，满足特殊情况灵活处理需求。

## 角色与功能模块

### 1. 普通学生

- **活动广场**：活动浏览、筛选、快截止提醒、一键申报
- **提交申请**：常规活动申报 / 新活动补录申报，材料上传，分数预览
- **我的申请**：申请状态追踪、驳回修改、异议接收与回复
- **我的成绩**：素质分可视化、总分计算、成绩明细查看
- **公示墙**：全班公示记录查看、异议提交

### 2. 审核学生（班委）

- **审核工作台**：本班申请初审、批量操作、材料核验、特殊情况转交
- **班级申请历史**：本班全量申请记录查询、审核追溯
- **权限边界**：仅查看本班数据，初审不直接计分，操作留痕

### 3. 辅导员（admin）

- **活动名录管理**：活动录入、学生补录审核、活动上下架
- **复审工作台**：申请复审、分数调整、异议处理、公示管理（仅管辖班级）
- **申诉工作台**：学生申诉裁决（采纳=恢复原始分并重新公示 / 驳回=维持原判）
- **成绩总览**：管辖班级排名、数据统计、批量导出
- **账号与班级管理**：CSV 导入学生、班委授权、周期切换、查看管辖班级（由系统管理员分配）

### 4. 系统管理员（superadmin）

- 唯一最高权限账号，不受管辖班级限制，数据覆盖全校
- 指定/调整每位辅导员的管辖班级（辅导员无权自改）
- 任命/撤销辅导员
- 活动截止时间仅为活动自身时间，不限制学生的综测申报

------

## 申请完整生命周期

1. 学生提交申请 → 系统防重复 / 规则校验
2. 班委初审（通过 / 驳回 / 转特殊）
3. 班级公示（2 天，全班可异议）
4. 管理员复审（通过 / 调整 / 驳回）
5. 学院公示（3 天）
6. 自动计分入账 → 成绩更新
7. 汇总期锁定 → 一键导出造册

## 技术栈

### 后端

- 语言：**Go (Golang)**
- Web 框架：**Gin**
- ORM：**GORM**
- 数据库：**PostgreSQL**（通过 Docker Compose 本地运行）

### 前端

- 框架：**Vue 3**
- 构建：**Vite**
- 语言：**TypeScript**
- 状态：**Pinia**

### 工程化

- 版本控制：`Git`
- 代码编辑器：`VS Code`
- 仓库托管：Gitee/GitHub

## 快速开始

### 1. 环境准备

- 安装 [Go 1.20+](https://go.dev/dl/)
- 安装 Git
- 安装 VS Code 并启用 **Go** 官方插件

### 2. 克隆项目

```
# 克隆到本地
git clone https://gitee.com/你的用户名/sdu_zongce_demo.git
# 进入项目目录
cd sdu_zongce_demo
```

### 3. 启动 PostgreSQL

```
docker compose up -d postgres
```

### 4. 初始化数据库

```
go run ./cmd/migrate up
go run ./cmd/seedclasses   # 测试账号矩阵（幂等，不覆盖密码）
```

> `go run ./cmd/seed` 会灌入完整演示数据（54 个账号），且会覆盖已有密码，慎用。

### 5. 启动后端

```
go run ./cmd/server
```

### 6. 启动前端

```
cd frontend
npm install
npm run dev
```

### 7. 访问前端

开发环境访问 `http://localhost:5173`。生产环境执行 `cd frontend && npm run build` 后，Gin 会托管 `frontend/dist`。
